# 声历 UI Style Guide

## 方向

声历是语音优先的本地 AI 日历。打开应用后，用户应直接看到日期、日历、待办和底部语音入口，不做营销式首页。

视觉方向是“晨光手帐”：晨雾绿、奶白、蜜桃粉、轻胶片感。它要像一本清爽的生活日程本，而不是冷冰冰的企业后台。

## 色彩

- 主背景：`MorningMist #F7FBF5`
- 卡片：`MilkGlass #FFFFFF`
- 主操作：`Eucalyptus #2F6E5F`
- 可用状态：`Sage #6FA887`
- 录音/风险：`Peach #F39A8B`
- 提醒强调：`Butter #F4CE77`
- 正文：`GraphiteLeaf #273B35`
- 暗色背景：`PineNight #12201B`

避免大面积紫蓝渐变、单一蓝绿色页面和装饰性浮动光斑。

## 组件

- 圆角最多 `8dp`，圆形只给图标按钮。
- 主屏保持日历优先；卡片只用于事件、草稿、设置分区和确认面板。
- 主屏底部仅固定一个语音按钮；文字输入、生成按钮和历史复用在输入幕布中显示。
- 月历星期和日期使用同一个 7 列网格，不能错列。
- 草稿确认默认折叠，支持单条保存、删除和全部保存。
- 设置页分为生成、权限与提醒、本地数据、危险操作。

## 文案

- 使用短句：说一句、生成、确认、保存、提醒、备份、导入。
- 错误提示说明下一步：例如“没有识别到语音，可以直接输入文字。”
- 不在界面解释架构、快捷键或内部实现。

## 商用要求

- 首次使用必须说明本地保存、按需联网和权限用途。
- 隐私说明必须明确：无账号、无广告、无分析 SDK、API key 本机加密。
- 备份不包含 API key。
- 清空本地数据必须二次确认。
