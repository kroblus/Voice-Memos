# 声历 UI Style Guide

## 方向

声历是语音优先的效率型日历，不做营销式首页。打开应用后，用户应该直接看见今天、近期安排和麦克风入口。整体气质是沉静、清晰、可快速扫读：像一本压得很平的工作手账，带一点有温度的纸张和墨色，而不是冷冰冰的企业后台。

## 视觉系统

- 主背景：`Paper #F4F1EA`，用于日历画布和主界面。
- 卡面背景：`Porcelain #FFFCF6`，只用于事件卡、确认面板和设置块。
- 主色：`InkTeal #215C5A`，用于主要按钮、今日标记和选中状态。
- 强调色：`Clay #D55F3D`，用于录音、待确认和风险提示。
- 辅助强调：`Ochre #B58A2A`，用于提醒、日期小标和轻量状态。
- 深色模式：用 `NightInk #111A1C` 承载背景，`MistTeal #A7D7CE` 做主操作。

避免大片单一蓝紫渐变，也避免把所有信息做成漂浮卡片。日历本身是主角，卡片只服务于重复事件项和确认弹层。

## 排版

- 中文标题使用系统衬线或 Compose `FontFamily.Serif`，制造手账标题感。
- 正文使用系统无衬线，优先可读性。
- 字号层级克制：主屏日期可以大，事件卡和面板标题保持紧凑。
- 字距保持 `0.sp`，不使用负字距。

## 组件规则

- 麦克风是首屏唯一大主操作，使用圆形图标按钮，不写长说明。
- 日历视图使用分段控件切换：月、周、日、清单。
- 事件块使用固定高度和颜色条，不因标题长度造成网格抖动。
- 待确认 AI 结果用底部面板展示，每个草稿都能编辑标题、开始时间、结束时间和提醒。
- 设置页只放必要项：DeepSeek API key、默认提醒、默认时长、精确提醒状态。

## 文案

- 用短句，避免解释 AI 功能。
- 主要动词：说一句、生成、确认、保存、提醒。
- 错误文案要可恢复：例如“没有识别到语音，可以直接输入文字。”
- 不在界面里讲快捷键、架构或功能说明。

## 动效

- 录音状态使用轻微脉冲和颜色变化，避免复杂动画影响语音输入专注度。
- 确认面板从底部进入，保存后轻量收起。
- 日历切换只做短距离淡入，不做夸张翻页。
