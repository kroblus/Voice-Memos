# 声历商用设计稿：晨光手帐

## 1. 产品定位

声历是一款本地优先的 AI 语音日历。核心承诺是：说一句话生成日程，数据留在本机，生成时才联网解析。

商用版本不做账号、广告、订阅或云同步。可信任感来自清楚的首次使用说明、可控权限、显式备份、可恢复错误文案和稳定提醒。

## 2. 视觉语言

设计方向为“晨光手帐”：清晨、轻盈、生活化、带一点胶片照片的温度，但不使用任何 Instagram 品牌资产、商标、图形或第三方素材。

颜色：
- `MorningMist #F7FBF5`：主背景，像晨雾底纸。
- `MilkGlass #FFFFFF`：卡片和底部输入托盘。
- `Sage #6FA887`：可用状态、轻量强调。
- `Eucalyptus #2F6E5F`：主按钮、选中日期、主要操作。
- `Peach #F39A8B`：录音、风险、待处理提示。
- `Sky #8CC7D8`：轻量信息提示，可用于后续插图或空状态。
- `Butter #F4CE77`：提醒、日期小强调。
- `GraphiteLeaf #273B35`：正文文字。
- `PineNight #12201B`：暗色背景。

组件规则：
- 圆角不超过 `8dp`，只在图标按钮上使用圆形。
- 日历是主角，卡片只用于事件、草稿、设置分区和确认面板。
- 首屏固定结构：品牌日期头部、视图分段控件、日历/清单、底部语音输入托盘。
- 主要操作使用图标按钮：语音、生成、保存、删除、设置、主题。
- 文案短而可恢复，不在界面解释技术架构。

## 3. 关键页面稿

首次使用：
- 标题：欢迎来到声历。
- 三个承诺：本地日历、语音优先、准点提醒。
- 可选输入 DeepSeek API key。
- 设置默认时长和提前提醒。
- 主操作：开始使用；辅助操作：系统权限。

首页：
- 顶部显示品牌和当前日期，右侧为今天、主题、设置。
- 月/周/日/清单分段切换。
- 月视图使用柔和 7 列网格，有事件的日期显示桃色点。
- 日视图突出下一项提醒。
- 底部输入托盘包含文本框、左侧语音按钮、右侧生成按钮。

草稿确认：
- 底部面板显示待确认数量。
- 每条草稿默认折叠，仅显示标题、时间、提醒、重复规则和置信度。
- 展开后可编辑标题、起止时间、提醒和重复次数。
- 支持单条保存、删除、全部保存。

设置：
- 生成：DeepSeek API key、默认时长、提前提醒。
- 权限与提醒：麦克风、通知、准点提醒状态和系统设置入口。
- 本地数据：JSON 备份、JSON 导入、ICS 导出、隐私说明。
- 危险操作：清空本地数据，必须二次确认。

Widget：
- 使用白色卡片、8dp 圆角和尤加利绿按钮。
- 内容只显示“下一项”、标题、时间和“说一句”入口。

## 4. 商用功能补全

已规划并落地：
- 首次使用流程。
- 权限与提醒中心。
- 隐私与数据说明。
- 显式 JSON 备份与导入。
- ICS 导出保留。
- 本地数据清空确认。
- Android 隐式自动备份关闭。
- Release 签名读取 `keystore.properties` 或环境变量。

备份格式：
- `schemaVersion = 1`
- `exportedAt`
- `events`
- 不包含 DeepSeek API key。
- 支持导入旧版事件数组 JSON。

发布配置：
- `targetSdk = 36`
- 不接入账号、广告、分析 SDK。
- Google Play Data safety 可按“用户提供文本在生成时发送给 DeepSeek、日程本地保存、不收集广告 ID、不共享账号标识”填写。
- 精确提醒权限只用于本地日程提醒；系统限制时退化为近似提醒。

## 5. 验收标准

功能：
- 新用户首次打开能理解本地保存、按需联网和权限用途。
- 没有 API key 时生成会引导去设置。
- 备份导出不包含 API key，导入后日程恢复并重新安排未来提醒。
- 清空本地数据会删除事件、设置、解析历史和本机 key。

视觉：
- 浅色模式以晨雾绿和奶白为主，主操作为尤加利绿。
- 暗色模式为松针绿，不出现大面积紫蓝渐变。
- 文本不重叠，按钮不少于 48dp，卡片圆角不超过 8dp。
- 日历列对齐、底部语音和生成按钮不重叠。
